# Security
Implemented: random challenges, expiry, atomic replay protection, ECDSA P-256 verification, RFC-style TOTP, database sessions, hashed session tokens, audit records, Android Keystore and BiometricPrompt.
Production hardening: HTTPS, secure HttpOnly SameSite cookies, CSRF protection where needed, encryption/KMS for TOTP secrets, device revocation, recovery design, rate limiting, monitoring, dependency scanning, secure app/browser handoff, independent penetration testing.
