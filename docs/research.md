# Research Plan
Compare OTP-only authentication with DPA dual proof.
Attack cases: valid OTP without device key; valid OTP with wrong key; replay; expired challenge; modified challenge; invalid OTP with valid signature; valid OTP plus valid signature; repeated guesses.
Measure acceptance/rejection, latency, usability and false rejection.
Do not claim global novelty without prior-art research; frame the contribution as the specific protocol, implementation and evaluation.
